🧠 dsh-model-memory

DeepSeek Harness（DSH）插件 —— 自定义模型思考等级管理与跨会话偏好记忆。
Reasoning-effort management & cross-session preference memory for DeepSeek Harness.

  • 「设置 → 模型」内嵌思考档位配置栏，一键开启 low / medium / high / max
  • 原子化写入 settings.yaml，热重载即时生效
  • 分渠道记忆最后使用的模型与思考强度，新建会话自动回填
  • 零界面冗余 · 升级 DSH 不丢插件与配置 · MIT 开源
